☁️ 跨设备同步

使用同一个 Supabase 账号登录手机和电脑，即可同步单词、掌握状态和复习时间。首次需要创建免费的 Supabase 项目并配置下面两项。

尚未连接云端。

首次配置步骤

  1. 打开 Supabase 控制台，创建一个项目。
  2. 在 Project Settings → API 中复制 Project URL 和 anon / publishable key，填入上方。
  3. 进入 SQL Editor，运行下方 SQL 建表并开启用户隔离。
  4. 手机和电脑分别填入相同配置，注册/登录同一个邮箱账号，再点「立即同步」。
create table if not exists public.greek_words (
  id text primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  greek text not null, meaning text not null, pronunciation text,
  category text, image_url text, memory_note text,
  known boolean default false, due bigint default 0,
  level integer default 0, updated_at timestamptz default now()
);
alter table public.greek_words enable row level security;
create policy "Users manage own Greek words"
on public.greek_words for all
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
create index if not exists greek_words_user_id_idx
on public.greek_words(user_id);

隐私提示：单词和学习进度会存储在你自己的 Supabase 项目中。不要把 service_role key 填进网页；这里只使用 anon / publishable key。云端同步需联网，离线时仍可使用本机已保存的词库。

建议每天学习 5–10 个新词。希腊语转写采用便于初学者阅读的近似写法，不等同于严格 IPA。
